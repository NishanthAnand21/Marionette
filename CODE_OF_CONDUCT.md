# Code of conduct

## The short version

Be straightforward and be kind. Criticise work, not people. Assume the person
you are replying to is competent and acting in good faith.

## Specifics

Expected:

- Technical disagreement, stated plainly, with reasons
- Saying "I was wrong" when you were — this project's own history contains
  several corrections, and they made it better
- Reporting a finding you are not certain about, labelled as uncertain

Not acceptable:

- Personal attacks, harassment, or demeaning comments
- Sexualised language or imagery, or unwelcome attention of any kind
- Publishing someone's private information
- Sustained disruption of discussion

## Security-specific

This is offensive-security tooling. That does not license hostility, and it
does not license using the project to help attack systems you have no
authorisation to test. Requests for help doing that will be closed.

## Enforcement

Report to the maintainer via
[a private security advisory](https://github.com/NishanthAnand21/Marionette/security/advisories/new)
if the matter is sensitive, or by opening an issue if it is not. Reports are
handled confidentially. Consequences range from a warning to a permanent ban,
proportionate to the behaviour.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org),
shortened deliberately — a code of conduct nobody reads protects nobody.
